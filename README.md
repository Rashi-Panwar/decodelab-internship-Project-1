Full Stack Project 1 - Responsive Frontend Interface

DecodeLabs Full Stack Development Internship

This project is a responsive frontend website developed as part of the DecodeLabs Full Stack Development Internship.

Project Overview

The project demonstrates a clean, responsive and user-friendly portfolio interface using HTML5, CSS3 and basic JavaScript.

The website is designed to work across desktop, tablet and mobile screen sizes.

Technologies Used

- HTML5
- CSS3
- JavaScript

Project Features

- Responsive navigation bar
- Hero section
- About section
- Skills section
- Projects section
- Contact form
- Basic JavaScript form interaction
- Responsive layout using CSS Flexbox and CSS Grid
- Mobile, tablet and desktop support
- Hover effects and smooth scrolling

Project Structure

Project 1/
│
├── index.html
├── style.css
├── script.js
└── README.md

File Description

index.html

Contains the main structure and content of the website using semantic HTML5 elements.

style.css

Contains the complete styling, responsive layouts, Flexbox, CSS Grid, colors, spacing, buttons, cards and media queries.

script.js

Handles the contact form interaction using JavaScript and displays a successful submission message.

Responsive Design

The website includes responsive layouts for:

- Desktop
- Tablet
- Mobile

CSS media queries are used to adjust the layout according to screen size.

How to Run

1. Open the project folder in Visual Studio Code.
2. Open "index.html".
3. Run the project using Live Server.
4. The portfolio website will open in the browser.

Expected Output

The website contains:

- A navigation bar at the top
- A hero section with project introduction
- About Me section
- Skills cards
- Projects section
- Contact form
- Footer

The contact form displays a success message after valid form submission.
